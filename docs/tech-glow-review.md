# 冷暖科技光效增强 · 2026-09-21

用户最新要求：既有光效可以更夸张，增强科技感。本轮据此增强冷暖颜色对比和动态层次，保留左右独立控制、床笠织物与现有主机摆放。

## 本次实现

- 加热采用红橙底色与金橙高光；制冷采用深蓝底色与电光青蓝高光。提高亮区强度，边缘继续渐隐至炭灰面料。
- 每区四组沿真实演示水路推进的高亮光脉，包含亮头、渐隐拖尾、窄亮芯和柔和光晕。保持与透视水流相同的路线与 0.019 弧长速度系数。
- 增加缓慢推进的弯曲宽幅光波和沿菱形织纹排列的微光点，光点使用 `fwidth` 抗锯齿。光波直接使用床面坐标，避免最近路径弧长切换造成大块断带。
- 床头供回水靠近区域收窄动态拖尾，减轻两个路径距离场分界处的光线杂乱。
- 所有效果仍使用各区自己的相位、强度及同一显示开关；待机平滑淡出，暂停冻结全部运动，透视模式让表面光退出。低动态偏好继续默认暂停。
- 修改运行文件仅为 `src/thermal-glow.js`、`src/thermal.js` 和 `src/thermal-controls.js`。未增加渲染通道、几何、外部素材或纹理采样次数。
