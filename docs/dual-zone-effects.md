# 双区温控与织物温感光 · 2026-09-21

用户确认左右温度独立控制，要求保留分区后的循环水路，并增加随温度变化的织物层光效。此前已按反馈参考 Eight Sleep 做柔光；2026-09-21 最新要求是效果更夸张、更有科技感，本轮在原柔光基础上增加高亮流动光脉、拖尾和宽幅光波。

视觉参考为 [Eight Sleep 官网](https://www.eightsleep.com/)（2026-09-20 查看），包括首页床面视频和 Couples 双区展示。参考点为融入织物的冷蓝／暖红色、柔和明暗过渡和发光时仍然可见的面料细节。实际着色器为本项目原创实现，没有使用官网贴图、视频或代码，也不声称复现其动画算法。

## 当前行为

- 左右以床尾朝床头观察为准，分别对应模型 X 轴负向和正向。
- 两侧独立保存设定温度、开关、冷暖模式、动画相位和水路颜色；可同时左冷右暖、左右同冷／同暖、单侧或双侧待机。
- 演示默认左 22℃、右 34℃；温度范围暂为 18–40℃，以 28℃ 作为冷暖视觉参考点。配置位于 `src/thermal.js`，并在两端页面注明为演示范围。
- 强度按离参考点的距离连续增加。待机光效平滑淡出，恢复时沿用当前温度；模式按钮在需要换冷暖区间时设置对应演示预设。拖动温度跨过参考点，会同步改变该侧冷暖状态。
- 光效直接写入织物 PBR 材质，保留绗缝表面和织纹。冷区由深蓝过渡到电光青蓝，暖区由红橙过渡到金橙高光；四周渐隐回炭灰织物，中部连续融合，无硬分割。视觉光晕相叠不代表温控状态或水路混合。
- 织物流光与透视层共用 `circuitCurves`，沿蛇形供回水路径及弯道推进。各侧有四组亮头与渐隐拖尾，叠加窄亮芯和宽光晕，仍以原水流速度驱动。床头供回水相距较近的部分收窄动态亮区，减少路径分界处的亮度跳变。
- 床面增加缓慢推进的弯曲宽幅光波和与菱形织纹方向一致的微光点。光点在波峰附近增强，用像素导数做抗锯齿。底光、流光、光波与光点均按单侧温差强度变化，并保留织物明暗调制。
- 温差增加时，底光与水路流光一起增强。「暂停动画」同时停止两区水流和织物流光运动；待机只淡出本区发出的光。
- 透视时表面光随面料淡出，保留各区冷暖水路。概念护套内有两组供回水路径，不代表实际确认的管径、接口或水力结构。
- 手机页默认整套床笠；竖屏调温时模型留在上方。HTML 继续内嵌全部代码、CAD 和贴图。

## 实现与验证边界

光效未新增后处理渲染通道或外部贴图请求，通过 `onBeforeCompile` 修改已安装 Three.js 的材质着色器。`src/thermal-route.js` 在初始化时由原水路曲线生成一张 512×512 RGBA8 距离／弧长纹理（1 MiB），无需浮点纹理扩展，随织物材质一起释放。这不构成真机性能保证。

光晕采用连续距离衰减，沿弧长移动的亮光限制在管线附近，避免相邻路径的弧长切换形成大块明暗接缝。宽幅光波和织纹光点直接使用床面坐标，与水路距离分开计算。颜色、中心高光与亮度均平滑切换，待机保留最后色相并淡出。所有运动继续受各侧相位与全局暂停控制，减少动态效果偏好仍默认暂停。属于视觉模拟，不是物理光散射或实际温度场。

检查涵盖水路坐标／方向／弯道弧长／双侧纹理通道、分区互不影响、单侧待机、温度与光感强度、真实渲染像素差异、暂停、切换透视、离线文件和触摸交互。报告见 `output/qa/checks.json` 与 `output/qa-mobile/checks.json`；当前视觉复核截图见 `output/qa-zones/`，本次调整前的双区／强光／细节截图与光效源码保留于 `output/qa-tech-glow/before/`。上轮 Eight Sleep 柔光记录保留在 `docs/eight-sleep-glow-review.md`。

当前未绑定设备真实目标／实时温度，也未验证实际加热、制冷、热传导、流量或功耗。真实 APP WebView 与手机硬件验收尚未进行。主机几何与原始设计资料未改动。
