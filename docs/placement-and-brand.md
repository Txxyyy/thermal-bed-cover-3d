# 默认摆放与床笠品牌标签 · 2026-09-20

本文件记录首次摆放与品牌织标修改。用户随后要求主机后移至枕头附近、床头中部接管并调细；最新方案与验证见 [床头接管调整](head-routing.md)。`DeRUCCI` 织标与正面朝前的方向继续保留。

## 实现

- `src/model.js` 将主机位置设为 `(1.3, 0, 0.62)`，绕 Y 轴旋转 90°，使带 Logo 与指示灯的局部 -X 正面朝向世界 +Z。位置是展示构图，不是安装尺寸要求。
- 水管终点跟随后接口变换，最后一段沿接口轴向进入。内部供回水管沿护套局部截面布置；外壳避让检查将路径转回主机局部坐标，避免旋转后误用世界坐标。
- 床笠织标保留原位置 `(0.55, 0.326, 1.015)`，改为单行暖灰色 `DeRUCCI`。文字使用字体近似，不是品牌原始矢量稿。
- 主机特写及 azimuth 视角跟随机箱旋转；面料细节镜头调整为完整展示品牌织标、包边与织物。
