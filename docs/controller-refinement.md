## 正反面与接管修正 · 2026-09-20

最新默认摆放：主机在床头右侧枕头附近 `(1.35, 0, -0.75)`，绕世界 Y 轴旋转 90°，正面指向床尾 +Z。床笠接口位于床头正中，软管展示外径为 26 mm。相机特写与 azimuth 链接跟随机箱旋转；供回水管使用护套局部截面排布，终点与后接口一起变换。以下 Logo 与接口定位均为主机局部坐标；此前摆放记录见 [床头接管调整](head-routing.md)。

- 用户确认后格栅和凹槽所在窄面为背面。转换模型局部 +X 为背部，-X 为带指示灯的正面。
- Logo 从原偏转 30° 的位置移到正面中轴，Z 中心与状态灯均为 0，高度保留约 0.254 m；逐顶点射线投射继续贴合 CAD 表面。
- 在背部下方凹槽的 CAD 壁面（`cad_32_grille`）射线定位接头座。管口沿 +X 朝外，编织水管绕到背部，再沿 -X 方向进入接头，避免穿过外壳或正面。接头尺寸与凹槽内的具体定位属于展示设计。
- 两侧供回水动画同步沿新的外部护套路径运行。主机材质、原始 CAD、织物散射光晕和左右温控逻辑未改动。
- 整体镜头略微拉远并右移，手机默认构图完整容纳新增背部弯管；主机特写略偏向正面，使 Logo 更容易查看。
- 共用检查 `scripts/check-controller-placement.mjs` 验证 Logo 面向和居中、后槽接头、管口连接与轴向、软管与主机包围盒的净距。此为展示几何检查，不是生产装配、弯曲半径或流体性能验收。
- 用户截图与修改前对照在 `output/qa-controller-fit/`。当前正面／背面截图为 `output/controller-study/angle-270.png` 与 `angle-90.png`，整体和手机截图见 `output/qa-zones/`。

## img2threejs 实际使用

- 来源：`https://github.com/img2threejs/img2threejs`，固定版本 `6e60b5e22419464b4853e01ddb6c0e6f6659a733`。
- 安装在项目 `.agents/skills/img2threejs/`，没有改动全局 Codex 配置。
- 从原始 PDF 提取 B 方案整体和细节图，保存在 `references/id-extracted/`。
- 调用了 `next.py`、`state.py`、参考图准入／检索／评估、`build_detail_inventory.py`、`analyze_texture.py`、`extract_pbr_evidence.py`、`turntable_gate.py`、`diagnose_render.py`。
- `.img2threejs/detail-inventory.json` 记录加水盖、灯带、边框、前后格栅、织物、曲面 UV、标识和底座共 9 项细节。
- 织物自动材质证据分数 `0.831`，超过工具阈值 `0.7`；采用 256px 的去光照颜色、法线和粗糙度贴图。分数是算法证据置信度，不是量产材质测量精度。
- 外壳两次提取均未达阈值，最佳 `0.661`。没有应用失败的外壳贴图；金属度／粗糙度／颜色由参考图人工拟合，仍是近似。

本次只采用与现有 CAD 优化相关的模块。未生成技能规定的全套 procedural spec，也未完成它的全部重建门禁；`.img2threejs/state.json` 保留未完成项，没有标记全流程通过。

## 模型变化

1. CAD 转换线性容差从 0.30 mm 调至 0.12 mm，角度容差从 0.25 调至 0.18。网格数量仍为 42，三角形从 12,740 增至 19,964；原始 STEP 不变。
2. 修正坐标轴朝向，使加水盖和底部指示灯位于参考图左侧。
3. 织物采用沿机箱周长的曲面 UV，把接缝放到背部格栅间隙，避免正面纹理断带。
4. 颜色贴图采用 sRGB；法线和粗糙度保持线性数据。格栅、加水盖、橡胶底部和外壳使用独立材质。
5. 文字标识通过射线投射贴合 CAD 织物表面；最新位置按上方正反面修正。它是字体近似，不是原始商标矢量稿。
6. 状态灯保留 ID 的蓝色，待机变暗；冷暖状态用床笠水路动画表达。
7. 主机镜头独立展示机箱，水循环按钮自动切换完整系统。修复画布点击误触发镜头重置的问题。

## 手机交付

`output/mobile/温控床笠-手机预览.html` 内嵌 Three.js、GLB 和所有纹理，约 2 MB，不依赖外部 CDN。`npm run export:mobile` 可重新生成。

手机页默认整套床笠视角，支持旋转、缩放、A/B 材质、主机特写与独立冷暖水路。`npm run preview:mobile` 只提供导出的 HTML，不暴露原始 STEP/PDF。具体打开方法见 `output/mobile/手机查看说明.md`。
