# 床头接管与主机后移 · 2026-09-20

按用户最新要求，主机移至床头右侧枕头附近；床笠进出水接口移到床头正中，连接软管明显调细。

## 当前展示方案

- 主机位置为 `(1.22, 0, -0.75)`，保留绕 Y 轴 90° 的朝向，正面指向床尾 +Z。该坐标用于展示布局。
- 床笠接口位于床头正中 `(0, 0.423, -1.034)`，沿 -Z 引出。软管向床头后方下垂，再弯向主机背部凹槽，末段沿接口轴线进入。
- 编织护套外径由 48 mm 调为 26 mm，约缩小 46%；床笠接头、主机接口套环、护套内四条供回水芯管同步调整比例。管径仍为视觉设计参数，不是确认的产品规格。
- 双区蛇形水路的供回水端移到各自床头中部，由短汇管分别连接软管内对应芯管。两种视图共用同一水路曲线，织物流光与透视水路保持一致；汇管增加水流动画，使连接处连续可读。
- DeRUCCI 床笠织标、主机正面标识、左右独立温控及冷暖柔光延续现有方案。
