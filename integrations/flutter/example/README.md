# Flutter 原生控件示例

在本目录执行 `flutter pub get`、`flutter run`。请先从仓库根目录执行 `npm run export:embed`。

滑杆只修改模拟目标温度，下拉框单独模拟设备实际运行状态，避免把设定温度误认为正在加热或制冷。18–40℃ 仅为演示范围。页面覆盖、断连、待机、暂停和视角可分别验证。

顶部“切换主题”按钮可切换 Flutter 的深浅主题和 3D 受光；WebView 透明叠在原生渐变背景上。

不包含真实设备协议、发布签名或发布配置。详见仓库 `docs/flutter-integration.md`、`docs/flutter-validation.md`。
